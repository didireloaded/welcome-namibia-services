# Ten-phase delivery plan

Working name: Arrival Namibia. The client has not confirmed whether to use that name or Welcome Namibia Services. The current code is a frontend product prototype. Information from the research and service proposals is treated as unconfirmed unless it describes generic planning guidance.

## Scope by phase

1. **Foundation.** Tailwind v4 theme variables for the provisional palette, typography, spacing, shape, elevation and motion. Improve text sizing, focus and reduced-motion behavior.
2. **Shared UI.** Reusable Button, Field, Card, Badge, Tabs, Dialog, Accordion, Progress, Table and EmptyState patterns.
3. **Site frame.** Shared public header/footer, portal type and navigation language.
4. **Public routes.** Home, services, visa/permit, transfers, medical coordination, vacations, eSIM enquiry, destinations, gallery, provider network and contact.
5. **Enquiries.** Service-specific four-step form, conditional checklist, review, draft save/resume and browser-local adapter. No shared SQLite/API backend and no local file contents.
6. **Client journey.** Status timeline and guidance, transfer details, local message thread and locally stored communication preferences.
7. **Agency workspace.** Search/filter queue, status history, document filename review states and driver assignment, all in the same browser store.
8. **Supporting content.** Destination and image-led inspiration pages, eSIM information and provider-network expectations. No fabricated testimonials or affiliations.
9. **Quality pass.** Responsive breakpoints, text legibility, focus/error states, reduced motion, route metadata, storage boundaries and browser verification.
10. **Delivery.** Handoff docs, production build, browser workflow and source package.

## Decisions that govern every phase

- The main proposition is coordinated arrival support: paperwork, transport and stay planning can be discussed together.
- Agency service fees, official fees and third-party costs are separate. No fee, timeline, eligibility result, approval, accreditation, provider, 24/7 support, client count or review is invented.
- Medical logistics are separate from clinical care. The prototype does not collect passport numbers or medical records.
- The supplied Namibia travel reference informs the photography, rounded composition and editorial hierarchy. Exact business colors, fonts and name remain unconfirmed.
- Local portal content is example data. Requests, messages and workspace changes remain in one browser and do not reach staff or any external service.
